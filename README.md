# henrycyber.com

Preview portfolio for Henry Hilf — local-first security tools, agentic systems, and field notes.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

| File | What to change |
| --- | --- |
| `lib/site.ts` | Name, email, socials, domain copy |
| `lib/content.ts` | Work briefs and notes |
| `app/` | Page structure and layout |
| `app/globals.css` | Color and type |

When the site feels like you, attach `henrycyber.com` in DNS and your host (Vercel works with this Next.js app as-is).
